# 🍽️ Menuverse AR — Interactive 3D & Augmented Reality Digital Menu

An immersive, frontend-only digital restaurant menu web application built with **React**, **TypeScript**, and **Three.js** / **`<model-viewer>`**. Designed to elevate the dining experience by allowing customers to inspect realistic 3D food dishes directly on desktop browsers or launch them in **Augmented Reality (AR)** on mobile devices via QR codes—no app download required.

## ✨ Key Features
- **Interactive 3D Dish Inspection:** Smooth 360-degree rotation, zoom, and lighting controls on desktop web browsers.
- **Augmented Reality (AR) via QR Code:** Mobile-optimized AR integration enabling users to scan a QR code and place realistic food items directly onto their table (supported on iOS Quick Look and Android Scene Viewer).
- **Custom 3D Asset Pipeline:** All 3D food models sculpted, textured, and optimized from scratch using **Blender** and **Python scripting** for optimal web performance.
- **Multilingual Localization:** Fully supports **English**, **Arabic** (with complete RTL UI adaptation), and **Turkish**.
- **Dark & Light Mode:** Seamless theme switching tailored for any restaurant ambiance or user preference.
- **Responsive QR-Ready Interface:** Sleek, mobile-first menu layout organized by categories, pricing, and dish descriptions.

## 🛠️ Tech Stack
- **Frontend Framework:** React, TypeScript, Vite, Tailwind CSS
- **3D & AR Rendering:** Three.js, Google `<model-viewer>`, WebGL
- **3D Modeling & Asset Pipeline:** Blender (3D modeling, PBR texturing, Python automation, GLB & USDZ export)
